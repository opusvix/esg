Sobre a ESG

A ESG Serviços Técnicos desenvolve aplicativos de gestão sob medida, pensados para rodar no próprio computador ou celular do cliente, sem assinatura obrigatória e sem prender os dados na nuvem de ninguém. A prioridade é número que fecha: toda conta tem fórmula documentada e é conferida por testes automáticos antes de chegar na tela.

O que fazemos

  • Gestão financeira
  • Controle de frota
  • Relatórios e indicadores
  • Apps para Windows e celular

Como trabalhamos

  • Dados no aparelho do cliente
  • Cada métrica com fórmula única
  • Testes automáticos
  • Publicação no GitHub Pages

Tecnologias

  • Python · FastAPI · SQLite
  • React · TypeScript
  • Tkinter · PWA
  • GitHub Actions
